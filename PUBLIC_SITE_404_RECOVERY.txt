YENİDEN DEPLOY TETİĞİ
1. Bu paketteki PUBLIC_SITE_REDEPLOY_TRIGGER.txt dosyasını public repo köküne kopyala.
2. GitHub Desktop'ta commit mesajı: Trigger GitHub Pages redeploy
3. Push origin.
4. Actions veya Settings > Pages alanında deployment tamamlanmasını bekle.
5. Gizli sekmede https://www.axyondev.com/ aç.
