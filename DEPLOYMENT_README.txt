AXYON.DEV PUBLIC SITE — DEPLOYMENT
==================================

Bu ZIP yalnızca herkese açık müşteri sitesidir.
İçeriğinde Zikirmatik, Kasa Defteri, hakkımızda, gizlilik ve veri silme sayfaları bulunur.

YÜKLEME
1. Mevcut GitHub Pages deposunun yedeğini alın.
2. Bu ZIP'in içeriğini depo köküne çıkarın.
3. CNAME, app-ads.txt, robots.txt ve sitemap.xml dosyalarını koruyun.
4. Commit/push sonrası şu adresleri kontrol edin:
   - /
   - /zikirmatik/
   - /kasa-defteri/
   - /privacy.html
   - /delete-data.html
   - /zikirmatik/privacy/
   - /kasa-defteri/privacy/

ÖNEMLİ
- AXYON_PRIVATE_WORKSPACE paketini bu depoya yüklemeyin.
- Private klasörleri Pages menüsünde göstermemek güvenlik sağlamaz; public GitHub deposundaki dosyalar yine görülebilir.
- Bu paket özel proje dosyalarını fiziksel olarak içermez.
