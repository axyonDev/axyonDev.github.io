# AxyonWonderNest — Placeholder Storefront v0.1.0

Static, dependency-free landing page prepared for:

`https://www.axyondev.com/wondernest/`

## Files
- `index.html` — page structure and copy
- `styles.css` — complete responsive design
- `script.js` — EN/TR/AR language switcher
- `assets/axyonwondernest-logo.png`
- `assets/axyonwondernest-banner.png`

## Publish
Upload **the contents of this folder** into the server directory that maps to `/wondernest/`.
The final public URL should be:

`https://www.axyondev.com/wondernest/`

No build step, Node.js or external library is required.
